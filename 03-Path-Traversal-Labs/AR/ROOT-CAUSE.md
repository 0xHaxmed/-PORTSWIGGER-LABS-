# أسباب ثغرات اجتياز المسارات (Root Cause Analysis)

## 1. نظرة عامة
تحدث ثغرات Path Traversal بسبب **دمج مدخلات المستخدم مباشرة داخل دوال نظام الملفات** دون التأكد من المسار الحقيقي النهائي (Canonical Path) على القرص الصلب.

---

## 2. الأسباب البرمجية الشائعة

### 1. الدمج الساذج للنصوص (Naive String Concatenation)
يقوم المطور بدمج مسار المجلد مع اسم الملف القادم من المستخدم:
```python
# كود مصاب
file_path = "/var/www/images/" + request.args.get("filename")
open(file_path) # إذا كان الباراميتر ../../../etc/passwd سيخرج من المجلد فوراً
```

### 2. الفلترة السطحية عبر استبدال النصوص لمرة واحدة
استخدام دوال مثل `str_replace("../", "", $path)`:
تقوم هذه الدالة بالمرور لمرة واحدة فقط على النص. إذا أرسل المهاجم `....//`، ستحذف الدالة `../` الوسطى وتلتحم النقطتان المتبقيتان مع السلاش ليشكلوا `../` جديدة تماماً!

### 3. عدم تطابق فك التشفير بين البروكسي والباك إند
عندما يقوم الـ WAF بفحص الرابط يفك التشفير مرة واحدة فيرى `%2e%2e%2f` غير ضارة. وعندما تصل للباك إند، يقوم إطار العمل بفكها مرة ثانية لتتحول إلى `../` وتنفذ الثغرة.
