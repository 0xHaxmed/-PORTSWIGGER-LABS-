# دليل الحماية والإغلاق لثغرات رفع الملفات (Remediation)

## 1. المعايير الهندسية الذهبية للحماية

1. **حفظ الملفات خارج مجلد الويب تماماً (Outside Web Root):**
   احفظ الملفات في مجلد غير متاح للمتصفحات (مثل `/var/storage/uploads/`) أو استخدم خدمات التخزين السحابي (AWS S3 / Google Cloud Storage).
2. **منع تنفيذ السكربتات في مجلد الرفع:**
   تعطيل مفسر PHP ومفسرات السكربتات داخل مجلد الرفع نهائياً عبر إعدادات السيرفر:
   ```apache
   # في خادم Apache
   <Directory "/var/www/uploads">
       php_admin_flag engine off
       Options -ExecCGI
       RemoveHandler .php .phtml
   </Directory>
   ```
3. **إعادة تسمية الملفات باسم عشوائي (Random UUID):**
   تجاهل اسم الملف الأصلي تماماً، وتوليد اسم عشوائي مثل `a9f3b2...png`، مما يحرم المهاجم من التحكم في الامتداد أو حقن `..%2f`.
4. **إعادة معالجة ورسم الصور (Image Re-encoding):**
   تمرير أي صورة مرفوعة على مكتبة معالجة صور (مثل PIL في بايثون أو GD في PHP) لإعادة رسم البكسلات وحفظها كصورة جديدة، مما يدمر أي كود شل محقون في التعليقات أو الميتاداتا.
