# 06 — File Upload Labs

Welcome to the **File Upload Vulnerabilities** module.
مرحباً بك في القسم السادس: **ثغرات رفع الملفات التنفيذية**.

> File upload flaws allow attackers to upload executable web shells to the target server—enabling instant Remote Code Execution (RCE) and total server takeover.
