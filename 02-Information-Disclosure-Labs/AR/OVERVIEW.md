## 1. ما هي ثغرة تسريب المعلومات؟
تحدث ثغرة **تسريب المعلومات (Information Disclosure / Information Leakage)** عندما يقوم تطبيق الويب - عن طريق الخطأ أو سوء الإعدادات - بكشف بيانات حساسة أو تقنية لأشخاص غير مصرح لهم بالاطلاع عليها.

هذه البيانات قد تشمل:
- **معلومات تقنية داخلية:** أنواع وإصدارات الخوادم، مسارات الملفات على السيرفر، وإصدارات مكتبات الأكواد (Frameworks).
- **أسرار وبيانات اعتماد:** مفاتيح تشفير، كلمات مرور قواعد بيانات، مفاتيح API خاصة.
- **كود مصدري (Source Code):** كود الباك إند الحقيقي، ملفات النسخ الاحتياطية، وسجلات الـ Git.
- **بيانات تخص المستخدمين أو الأعمال:** أرقام بطاقات ائتمان، إيميلات، أو تفاصيل سرية.

في قائمة **OWASP Top 10**، تندرج هذه الثغرة تحت تصنيف **Security Misconfiguration (A05)** وتعد حجر الأساس لأخطر الهجمات المعقدة.

## 2. أخطر صور تسريب المعلومات

| الصورة | الوصف | الخطر الأمني |
|---|---|---|
| **رسائل الأخطاء التفصيلية (Verbose Errors)** | إظهار الـ Stack Trace وأخطاء الداتابيز للمستخدم. | يكشف نوع وإصدار الـ Framework بدقة لتطبيق ثغرات جاهزة (1-day exploits). |
| **صفحات التصحيح (Debug Pages)** | ترك صفحات مثل `phpinfo()` أو Swagger أو Django Debug مفتوحة في الإنتاج. | تكشف كل متغيرات البيئة (Environment Variables) ومفاتيح AWS السحابية. |
| **ملفات النسخ الاحتياطي (Backup Files)** | ترك ملفات مثل `.bak` أو `config.php.old` في مسارات عامة. | تحميل كود المصدر صريحاً وقراءة كلمات مرور قواعد البيانات. |
| **مجلدات الـ Git المكشوفة (`.git/`)** | نشر مجلد التحكم بالنسخ على السيرفر العام. | استخراج تاريخ التعديلات السابق وسرقة الكود بالكامل حتى لو حُذفت الأسرار لاحقاً. |
| **طرق HTTP التشخيصية (TRACE / OPTIONS)** | ترك أوامر تعيد طباعة ترويسات الطلب للمستخدم. | كشف ترويسات الثقة الداخلية المستخدمة بين البروكسي والباك إند وتزويرها. |

---

## 3. لماذا تعتبر هذه الثغرة "جسر الاختراق"؟
المخترق نادراً ما يتوقف عند معرفة إصدار السيرفر؛ تسريب المعلومات هو الخطوة رقم 1 التي تمكنه من:
1. العثور على ثغرات معروفة (CVEs) مطابقة لنفس الإصدار.
2. تجاوز حواجز الحماية (WAF / Authentication Bypass) عبر ترويسات مسربة.
3. السيطرة التامة على قواعد البيانات عبر أسرار مسربة في ملفات `.bak`.
