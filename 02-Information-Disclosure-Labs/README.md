# 02 — Information Disclosure Labs

Welcome to the **Information Disclosure** vulnerability module.
مرحباً بك في القسم الثاني: **ثغرات تسريب المعلومات**.

> Information disclosure occurs when an application reveals sensitive data—framework versions, error traces, backup files, or credentials—that attackers leverage for exploitation.
