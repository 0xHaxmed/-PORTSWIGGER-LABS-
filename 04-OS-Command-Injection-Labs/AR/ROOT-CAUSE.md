# أسباب ثغرات حقن أوامر النظام (Root Cause Analysis)

## 1. نظرة عامة
تحدث ثغرة **OS Command Injection** عندما يستدعي التطبيق مفسر الأوامر (Command Shell) ويمرر له نصاً يحتوي على متغيرات قادمة من المستخدم دون عزل المعاملات عن الأوامر.

---

## 2. الخلل البرمجي الجوهري: تشغيل الشل (Spawning a Shell)
عندما يستخدم المطور دوالاً مثل `os.system()` في بايثون أو `system()` في PHP أو `exec()` في نود جي إس:
- هذه الدوال لا تستدعي البرنامج المطلوب مباشرة، بل تقوم بتشغيل شل كامل (`/bin/sh -c "command"`).
- مفسر الشل يقوم قبل تشغيل أي شيء بفحص السطر بالكامل والبحث عن الحروف الخاصة (`&`, `;`, `|`).
- إذا وجد فاصلاً، يعتبر ما بعده أمراً برمجياً مستقلاً ينفذه بصلاحيات الخادم!

```c
// كود مصاب بلغة C / PHP
char cmd[256];
sprintf(cmd, "check_stock.sh %s", user_store_id);
system(cmd); // إذا كان user_store_id يحتوي على | whoami سينفذه الشل فوراً!
```
